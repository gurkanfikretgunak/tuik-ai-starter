# projects/

`/new-project <ad>` komutu yeni projeyi `projects/<ad>/` altında üretir. Bu klasör şablon deposunun parçası değildir; üretilen projeler kendi git deposuna taşınabilir.

- Şablonlar: `templates/` (`fullstack-minimal`, `go-service`, `py-calculation`, `web-dashboard`).
- Veri: yalnızca sentetik/anonim (`data/sample/` kuralı burada da geçerli).
- Akış: `.claude/skills/proje-baslat/SKILL.md`.
