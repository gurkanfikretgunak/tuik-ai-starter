# İnceleme listesi
1. **Veri gizliliği**: gerçek veri, kişisel veri, sır var mı?
2. **Doğruluk**: sınır durumları, hata yönetimi, sözleşmeyle uyum.
3. **Güvenlik**: girdi doğrulama, enjeksiyon, yetki.
4. **Test**: yeni davranışlar test edilmiş mi, test anlamlı mı?
5. **Okunabilirlik**: isimlendirme, gereksiz karmaşıklık, ölü kod.
Çıktı: Kritik / Önemli / Öneri başlıkları, dosya:satır ve somut düzeltme.
