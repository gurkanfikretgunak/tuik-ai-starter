# Gösterge tanımı
Alanlar: kod, ad (TR/EN), birim, periyot (aylık/çeyreklik/yıllık), kapsam, kaynak, metodoloji notu, revizyon politikası, gizlilik sınıfı.
Çıktı `packages/contracts/` altında JSON Schema olarak ve örnek bir kayıtla verilir. Mümkünse SDMX kavramlarıyla (boyut, ölçü, öznitelik) uyumlu adlandır.
