# Tasarım dokümanı
(Şirket Sicil `DESIGN.md` pratiğinden uyarlanmıştır.)
1. `docs/tasarim/DESIGN.template.md` dosyasını proje köküne `DESIGN.md` olarak kopyala.
2. **Referans tablosu doldur:** benzer ürün/tasarım sistemi (ör. GOV.UK, Infor, kamu portalları) + URL + "alınan desen". Kopyalama değil, desen çıkarma.
3. Tema (açık/koyu), renk token'ları, tipografi, sayı/kimlik biçimi (`tabular-nums`), durum rozetleri, boş/hata/yükleniyor durumları, erişilebilirlik (kontrast, klavye).
4. Yeni ekran bu dokümana uyar; sapma gerekiyorsa önce dokümanı güncelle.
5. İstatistik arayüzü ek notları: kaynak ve dönem notu, birim, "geçici/kesin" etiketi, gizli hücre gösterimi, örnek veri uyarısı.
